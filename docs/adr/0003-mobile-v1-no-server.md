# ADR-0003 · 앱 1차는 서버·로그인 없이 기기 안에서 계산한다

- 상태: 채택 · 2026-09-13

## 배경
isa-lab-api(Spring Boot)에 `/compare` `/annual` 같은 세금 API가 있다. 앱이 이를 호출할지, 엔진을 기기에서 돌릴지.

## 결정
1차는 **기기 안에서** 엔진을 돌린다. 입력값은 AsyncStorage에만 저장한다. 서버·계정·네트워크 없음.

## 이유
- 입력이 자산군별 실현손익 5개뿐이라 서버가 할 일이 없다. 오프라인에서도 30초 안에 답이 나와야 한다
- 개인정보 수집 「없음」으로 스토어 심사가 단순해진다
- Ponytail 사다리: "서버 진짜 필요해? → 아니오"

## 결과
- 2차(모의계좌 동기화·종목 단위 입력)에서 isa-lab-api를 붙인다. 그때 API 계약은 이미 있다
- 앱 코드에 세율이 없다 — 룰셋 갱신은 `packages/tax-engine/src/rules.ts` 한 곳
